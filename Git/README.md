# Git & GitHub Basics

This repository contains my notes and practice while learning Git and GitHub.
The goal of these notes is to understand version control, track project changes, work with branches, and manage repositories efficiently.

# Topics Covered
- Git initialization
- Working Directory, Staging Area, and Repository
- Adding and committing files
- Viewing commit history
- Restoring changes
- Comparing file versions with Git Diff
- Branch creation and management
- Merging branches
- Handling merge conflicts
- Working with remote repositories
- Push and Pull operations
- Git Ignore (.gitignore)
