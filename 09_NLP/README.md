# NLP Fundamentals with Python

This repository contains my practice notebooks while learning the basics of Natural Language Processing (NLP).

The project covers the early stages of the NLP pipeline, including text cleaning, preprocessing, vectorization, and text classification.

# Topics Covered
- Data collection and loading datasets
- Text preprocessing
- Lowercasing
- Removing punctuation
- Removing numbers
- Removing emojis
- Stopword removal
- Tokenization
- Label encoding for text classification
- Text vectorization
- Bag of Words (BoW)
- TF-IDF
- Multinomial Naive Bayes
- Logistic Regression
