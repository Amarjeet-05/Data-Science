## NumPy 
This folder contains practice notebooks focused on **numerical computing using NumPy**, which is the foundation of data science libraries.


## Topics Covered

- Creating NumPy arrays
- Slicing and indexing
- Boolean masking
- Broadcasting
- Mathematical functions
- Statistical operations
- Basic image processing using NumPy


### Goal
To understand how numerical data is handled efficiently and prepare for working with Pandas and ML libraries.
