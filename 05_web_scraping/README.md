## Web Scraping 
This folder contains my learning and practice related to **web scraping using HTML**, focused on collecting data from websites for analysis.

### Topics Covered
* Understanding HTML structure
* Inspecting web pages
* Extracting data using Python
* Parsing HTML elements (tags, classes, ids)

### Tools & Libraries
* requests
* BeautifulSoup

### Goal
To learn how to collect raw data from web pages and convert it into structured formats suitable for data analysis.
